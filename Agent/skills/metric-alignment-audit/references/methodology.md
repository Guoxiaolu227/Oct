# Metric Alignment Methodology

Sokolova and Lapalme (2009; DOI `10.1016/j.ipm.2009.03.002`) analyze how
classification measures behave across task structures. Flach (2019; DOI
`10.1609/aaai.v33i01.33019808`) motivates treating performance evaluation as a
design problem rather than selecting a familiar scalar.

Build an explicit target-to-measure mapping. Consider class-conditional error,
threshold dependence, ranking versus calibrated probability, macro versus
micro aggregation, subgroup scope, and whether a proxy has been validated for
the claimed consequence. The paper's application and claim determine which
properties matter.

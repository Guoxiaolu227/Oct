# Sampling and Split Methodology

Datasheets for Datasets (Gebru et al., 2021; DOI `10.1145/3458723`) organizes
questions about motivation, composition, collection, processing, uses, and
limitations. Data Statements (Bender and Friedman, 2018; DOI
`10.1162/tacl_a_00041`) connects described populations to precision in
generalization claims.

Use these sources to reconstruct the sampling frame, not as a checklist score.
The inferential question is whether collection, filtering, and partitioning
match the manuscript's target estimand and generalization unit. A mismatch can
be temporal, institutional, demographic, linguistic, event-level, or
entity-level.
